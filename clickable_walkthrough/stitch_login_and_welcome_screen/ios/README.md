# AdaptFit AI (iOS)

This folder contains a minimal **native iPhone app** (SwiftUI) that bundles the exported HTML screens and displays them inside the app using `WKWebView`, with native navigation.

## How to run

1. Install **Xcode** (not just Command Line Tools).
2. Open `ios/AdaptFitAI.xcodeproj` in Xcode.
3. Select an iPhone Simulator (e.g. iPhone 15).
4. Press **Run**.

## What you get

- **Run demo flow**: a simple Back/Next walkthrough of the screens.
- **All screens**: a list to open any page directly.
